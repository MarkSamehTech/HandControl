# Hand Gestures Control — Android

نسخة الموبايل من تطبيق ويندوز. بتتحكم في الموبايل كله بحركات إيدك من الكاميرا الأمامية، والتتبع بيحصل على الجهاز نفسه من غير إنترنت.

## 1) إزاي تطلّع الـ APK من GitHub (من غير ما تثبّت أي حاجة)
1. اعمل Repository جديد على GitHub.
2. ارفع محتويات الفولدر ده كلها (Add file → Upload files). تأكد إن فولدر `.github/workflows/build-apk.yml` اترفع. لو الفولدر المخفي مارفعش، اعمل ملف جديد بنفس المسار والصق محتواه.
3. روح تبويب **Actions** ← **Build APK** ← **Run workflow** (أو هيشتغل لوحده مع أول رفع).
4. استنى حوالي 5 إلى 8 دقايق، وبعدها من صفحة التشغيل نزّل **HandGesturesControl-apk** (ملف zip جواه الـ APK).
5. ابعت الـ APK للموبايل وثبّته (لازم تسمح بـ "التثبيت من مصادر غير معروفة").

الـ workflow بيحمّل نموذج اليد الرسمي من MediaPipe وقت البناء ويدمجه في الـ APK، فالتطبيق بيشتغل بعدها من غير نت.
لو عايز تبني على جهازك: نزّل `hand_landmarker.task` في `app/src/main/assets/` وافتح المشروع في Android Studio.

## 2) أول تشغيل
1. افتح التطبيق واسمح للكاميرا والإشعارات.
2. فعّل **خدمة إمكانية الوصول** (Hand Gestures Control). دي اللي بتخلّي التطبيق يلمس الشاشة وينفذ رجوع/الرئيسية بدالك، وأندرويد مفيهوش طريقة تانية لده.
   - على أندرويد 13+ لو الزرار رمادي: معلومات التطبيق ← ⋮ ← "السماح بالإعدادات المقيّدة"، وبعدين فعّل الخدمة.
3. اضغط **تشغيل التحكم**. الكاميرا هتفضل شغالة حتى لو فتحت أي تطبيق تاني (إشعار فيه إيقاف مؤقت وإغلاق).

## 3) الأوضاع
- **الأوامر العادية** (بدون لمس): 👍/👎 صوت، ✋ تشغيل/إيقاف، ✊ كتم، ✌️ الفيديو التالي، ☝️ السابق، 🤙 تمرير، 👉 رجوع، 👈 التطبيقات الأخيرة، 🤘 إيقاف الالتقاط، 🖖 استئناف، 👌 وضع اللمس. كل حركة قابلة للتغيير.
- **وضع اللمس** (بديل وضع الماوس): حرّك إيدك فتتحرك النقطة. 🤏 الإبهام + السبابة = لمس (ضغطة / إمساك / سحب)، + الوسطى = رجوع، + البنصر = دبل تاب. 🤙 تمرير، ✌️ كيبورد الموبايل، ☝️ رجوع، 🖖 الرئيسية، 🤘 خروج (كلها بتثبيت نص ثانية تقريبًا).
- الكيبورد هو كيبورد الموبايل الأصلي: اضغط على أي خانة بالقرصة وهيظهر لوحده، وبتكتب بالقرصة على حروفه.

## 4) ملاحظات
- تطبيقات البنوك وبعض التطبيقات الحساسة بتحجب لمسات خدمات إمكانية الوصول، فممكن ما يشتغلش جواها.
- لو تطبيق تاني فتح الكاميرا الأمامية (مكالمة فيديو مثلًا)، أندرويد بيوقف الكاميرا عندنا.
- الكاميرا الشغالة بتستهلك بطارية. وقّف التحكم لما مش محتاجه.
